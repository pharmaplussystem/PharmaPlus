PharmaPlus V7 – START HERE

1. UNZIP the package.
2. Keep your existing Supabase project/database. DO NOT create a new project.
3. Open Supabase → SQL Editor → New query.
4. Open this package's supabase_schema.sql, copy ALL of it, paste into Supabase SQL Editor and Run.
   This V7 schema adds wholesale/retail medicine prices, pending sales, complete/reject sale functions,
   and safe historical links for deleted medicines.
5. Open index.html (or deploy the folder to GitHub Pages/Netlify/etc.).
6. If Supabase connection is requested, enter the Project URL and browser-safe Publishable/anon key.

IMPORTANT V7 WORKFLOWS

MEDICINES
- Inventory no longer has an Actions button.
- Click a medicine row to open Details.
- Details contains the Actions drawer.
- Edit, change quantity/prices, archive/restore and permanent delete are inside the drawer.
- Admin and Manager can change quantity and prices.
- Medicine entry suggests matching generic/brand/category information from history.
- Generic + brand is displayed as: Generic (Brand).
- Wholesale and Retail prices are stored separately.

SALES
- Search/select medicines from current active stock; generic, brand, batch and expiry are shown.
- Wholesale customers use the Wholesale price; Walk-in customers use the Retail price.
- Printing a provisional receipt creates a PENDING sale.
- Pending sales do NOT deduct stock.
- Complete the sale to deduct stock.
- Reject the sale to leave stock unchanged.
- Sales has All / Completed / Pending / Rejected filters.
- Click a Pending status to complete or reject it.
- Receipt does not show a payment-received/not-received status.
- Receipt keeps the payment METHOD and batch number.

REPORTS
- The Generate Report button was removed.
- Select a date range and open a category.
- Reports are split into individual report tiles.
- Click a tile to open the complete report.
- Print/PDF/Excel options are inside the individual report only.
- This prevents printing the whole inventory when only one report is needed.

RESPONSIVE DESIGN
- The system is designed to fit the screen without horizontal page scrolling.
- Long content uses vertical scrolling.

If Supabase shows an error while running the schema, copy the exact error message before changing anything.

V7 ADJUSTMENT NOTE
- A pending sale's Receipt button can open/print the provisional receipt at any time.
- Clicking the Pending status completes the sale and deducts stock; it does not reopen the receipt.


IMPORTANT REPAIR IN THIS BUILD
The previous Management package was missing the live Inventory/POS JavaScript handlers from index.html. This build restores those handlers. Inventory, Add Medicine, New Sale, medicine details/actions, sale item suggestions, receipts and report detail actions are wired into the page. The service-worker cache was also bumped to v11.
